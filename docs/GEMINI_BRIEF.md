# アプリ仕様 申し送り（Claude Code → Gemini Spark）

このファイルが唯一の正本です。`npm run sync-gemini` でスプレッドシートの
『アプリ仕様_Claude→Gemini』タブへ全文が転写されます。

---

## 1. このアプリの役割

薫之介さん専用のモバイルダッシュボード（Next.js / Vercel）。
スプレッドシートを共通データベースとして、Gemini Spark と役割分担しています。

- **Gemini Spark**: 食事写真の解析、カロリー/PFCの算出、翌日メニューの立案 → **スプレッドシートに書く**
- **アプリ**: 体重・歩数・睡眠・筋肉痛・筋トレ実績の記録 → **スプレッドシートに書く**
- **アプリ**: Gemini が書いた数値と計画を **読んで表示する**

## 2. タブ構成と役割

| タブ | 書き込む人 | 内容 |
|---|---|---|
| `ボディメイク＆減量プロジェクト_総合管理シート` | 両方 | A〜K列の日次ログ |
| `進捗＆予測ダッシュボード` | Gemini | AI次回計画メニュー |
| `CLAUDE_MD_MASTER` | Gemini | 最新のCLAUDE.md全文（A1セル） |
| `アプリ仕様_Claude→Gemini` | Claude Code | このファイルの全文（自動更新） |

## 3. 日次ログ（A〜K列）の書式

| 列 | 項目 | 主に書く人 |
|---|---|---|
| A | 日付 `YYYY-MM-DD` | 両方 |
| B | 体重(kg) | アプリ |
| C | 摂取カロリー(kcal) | Gemini |
| D | タンパク質P(g) | Gemini |
| E | 脂質F(g) | Gemini |
| F | 炭水化物C(g) | Gemini |
| G | 消費カロリー(kcal) | Gemini |
| H | 歩数 | アプリ |
| I | 筋トレ部位・メニュー | アプリ |
| J | その他運動 | Gemini |
| K | メモ・コンディション | 両方 |

### K列（メモ・コンディション）の取り扱い — 重要

アプリは K列に `睡眠: / 筋肉痛: / 明日:` の3項目を ` / ` 区切りで**先頭に**書きます。

```
睡眠: 7.5時間 (23:30-07:00) / 筋肉痛: 胸, 腕 / 明日: アルバイト / （Geminiの自由記述はここに残る）
```

- アプリは上記3キーで始まる断片**だけ**を置き換えます。
- **Gemini側の自由記述は消しません。** 逆に、Gemini がこの3キーを書き換えると
  アプリの記録と競合するので、この3つはアプリに任せてください。

## 4. AI次回計画メニューの書式 — 重要

`進捗＆予測ダッシュボード` タブの**任意のセル**に、次の形式で書いてください。
アプリは全シート・全セルを走査して見出しを探します。

```
AI次回計画メニュー (2026/08/10 Push 自宅)
ダンベルベンチプレス: 8kg*2*10(アップ), 24kg*2*8(メイン1), 18.5kg*2*10(バックオフ) | レスト150秒
フレンチプレス(両手): 12kg*1*12 | レスト60秒
```

- 見出し: `AI次回計画メニュー (YYYY/MM/DD 部位 場所)`
- 見出しの**直下の行から空行まで**を1つの計画として読みます。
- 各行: `種目名: 重量kg*本数*回数(ラベル), ... | レストN秒`
  - `本数` はダンベルの個数（2 = 両手）
  - ラベルに「アップ」を含むセットはウォームアップ扱いで、目標回数の算出から除外します
  - レストは `分` でも可（`レスト2.5分`）
- アプリはこれを筋トレ画面にワンタップで取り込み、重量・回数・レスト秒をプリセットします。

## 5. 絶対禁止（NG）種目

- **ダンベルフライ**: 提案しないでください。アプリ側でもプリセットから完全除外しています。

## 6. 店舗別の機材ルール

- **赤坂店 (LifeFit)**: レッグカール**なし** / アシストチンニング**あり**
- **牛久・自宅近く店 (LifeFit)**: レッグカール**あり** / アシストチンニング**なし**

## 7. 現在の機能一覧

**ホーム**
- 体重推移グラフ（実績・理想線・12週先の予測線）
- マイルストーン（87 / 85 / 82 / 80 / 77 / 75kg）
- 本日のカロリー・PFC・歩数（Gemini がシートに書いた値を表示）
- 本日のAI計画カード

**今日**
- 体重・歩数・就寝/起床時刻・筋肉痛部位・明日の予定を記録
- 保存内容はその日のうちフォームに残ります
- スプレッドシート連携時は B/H/K列へ反映

**筋トレ**
- 「筋トレMEMO」風の赤基調UI、カレンダー、月間/累計の合計負荷量
- AI計画のワンタップ取り込み
- レストタイマー（60/90/120秒）、1RM自動計算
- **種目の自作追加・削除**（プリセットに無い種目に対応）

**設定**
- 各ユーザーが自分のスプレッドシート（GASウェブアプリURL）を登録
- 未連携でも記録は端末に保存される。連携するとカロリー分析とAI計画が有効になる

## 8. マルチユーザー構成

サーバー側に共有の接続先は持ちません。各ユーザーが自分のシートを登録する方式なので、
**他人が薫之介さんのシートを見ることはできません。**
新規ユーザー向けに、数値の入っていないテンプレートを配布しています。

## 9. Gemini Spark へのお願い

1. カロリー・PFC・消費カロリー・その他運動は**シートに直接**書いてください（アプリは読むだけです）。
2. 翌日メニューは §4 の書式を厳守してください。書式が崩れるとアプリが読み取れません。
3. K列の `睡眠: / 筋肉痛: / 明日:` はアプリの領域です。それ以外は自由に追記してください。
4. CLAUDE.md を更新するときは `CLAUDE_MD_MASTER` の A1 に**全文**を入れてください。
   セクションを削ると、その仕様がローカルから失われます。
